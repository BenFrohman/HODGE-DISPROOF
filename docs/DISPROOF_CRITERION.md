# Disproof criterion

**Author:** Benjamin Stanley Frohman (@BenFrohman)
**License:** Apache-2.0
**Clay status:** open

## Theorem (characterization)

Let `D = (X, ω)` be a smooth polarized complex projective fourfold. The
following are equivalent:

1. Hodge fails on `D` in codimension 2.
2. `Δ_miss(D) ≠ ∅`.
3. There exists `γ ∈ P^4(X,Q) ∩ H^{2,2}(X)` with `γ ∉ im(cl_X)`.

This is Lemma 1, rewritten. It does not prove Hodge false. It names the
object a disproof would have to exhibit.

## What is not a theorem

`∃ D, Δ_miss(D) ≠ ∅` is the Clay negation on fourfolds. It is not proved.

Very general high-degree hypersurfaces have `Δ_Hdg = ∅`.
Cubics and the Fermat sextic have `Δ_Hdg ≠ ∅` and `Δ_miss = ∅`.
No host with `Δ_miss ≠ ∅` is known.

Making the characterization a theorem does not release the Millennium
problem. Releasing a disproof requires inhabiting clause (3).
