# Hodge on a fourfold D

**Author:** Benjamin Stanley Frohman (@BenFrohman)
**License:** Apache-2.0
**Clay status:** open

Fix a smooth polarized complex projective fourfold `D = (X, ω)`.

```
L(D)  ⇔  Δ_miss(D) = ∅
```

`L(D)` means every primitive rational `(2,2)`-class is algebraic.
`Δ_miss(D)` is those classes outside `im(cl_X)`.

Hodge holds on `D` if and only if the miss locus is empty.
A disproof is one `D` with `Δ_miss(D) ≠ ∅`.

No three-part chain with `Δ_Hdg = ∅` is used.
