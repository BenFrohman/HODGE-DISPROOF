# Note: the global chain is not a theorem

**Author:** Benjamin Stanley Frohman (@BenFrohman)
**License:** Apache-2.0
**Date:** 24 September 2026

The chain

```
L  ⇔  Δ=∅  ⇔  (Lemma 1 ∧ Lemma 2)
```

is **not** a theorem if `Δ` means `Δ_Hdg` (extra primitive Hodge classes).

Counterexamples to `L ⇒ Δ_Hdg=∅`: cubic fourfolds, Fermat fourfolds,
and (if Cor. 1.2 stands) the Lin–Zhang split family. Hodge can hold with
extra algebraic primitive classes.

Noether–Lefschetz vanishing (`Δ_Hdg=∅` on a very general high-degree
host) is Lemma 2: it *implies* `L`, it does not refute Hodge.

Locked replacements: `docs/LOCKED_LEMMAS.md`.

```
Lemma 1:  L(D) ⇔ Δ_miss(D)=∅     (definition)
Lemma 2:  Δ_Hdg(D)=∅ ⇒ L(D)
```

This note is not a disproof of the rational Hodge conjecture.
